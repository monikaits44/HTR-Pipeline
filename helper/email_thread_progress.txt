On 2025-12-01 19:54, Chavan, Monika Radhakisan wrote:Dear Prof. Vincent,

Please find below the current status of my work:
------------------------------------------------------------------------------------ Completed:
Investigated the issue you pointed out regarding the distorted overlays,
Originally, I upscaled the 8×64 ViT token grid to the full image size using standard bilinear interpolation.
This implicitly assumed that the patch grid height corresponds smoothly to the full image height, which is not true in HTR
Since ViTs for handwriting use rectangular patches with only a few patch rows covering the entire vertical dimension, bilinear upscaling caused the heatmap to be stretched and smeared along the y-axis
Implemented a patch-aligned expansion method to replace the incorrect upscaling.
The fix:
I replaced the upscaling operation with patch- aligned expansion, where each patch row and column is replicated according to its true receptive-field size in the original image.
This removes the vertical distortion entirely and produces overlays that accurately preserve ViT patch geometry.
Prepared a side-by-side comparison (“current vs corrected”) showing the improved attention overlays.
Please find attached samples.
