## Archived / superseded documentation

Older execution guides and superseded notes have been moved (not deleted)
into the workspace-local `archive/` directory:

| Archive location | Contents |
|------------------|----------|
| `archive/helper_docs_v1_feb_mar_2026/` | Original execution guides (Feb–Mar 2026) |
| `archive/legacy_documents/` | Superseded documentation versions |
| `archive/helper_notes/` | Informal notes / email threads |
| `archive/papers/` | Reference PDFs of cited works |
| `archive/problem statement/` | Original project brief |
| `documents/archiev_docs/` | Older revisions of the report and analyses |

`archive/` is git-ignored: contents are retained locally and on internal
backups but are **not published to GitHub**.
